# ⚡ ZeroSQL AI (V2) - Production AI SQL Agent & Dataset Analytics Platform

ZeroSQL AI V2 is a secure, dynamic, schema-aware AI SQL Agent and dataset analytics engine. It enables non-technical users to converse with structured relational databases in plain English, query dynamic custom datasets, discover curated industry datasets, and perform multi-turn data analytics with automatic visual chart generation.

## 🛡️ Security Architecture & Separation of Concerns

### 1. Dual-Role Database Access Model
* **AI Agent Read-Only Path**: The AI Agent strictly connects via `DATABASE_READONLY_URL` with transaction-level `read_only = True`. The agent has zero privileges to create, modify, or delete database tables.
* **Backend Admin Write Path**: Dynamic table creation, bulk insertion, and metadata management are strictly isolated to authenticated backend services using `DATABASE_ADMIN_URL`.

### 2. Defense-in-Depth SQL Guardrails
Every SQL query generated by the LLM passes through a multi-stage security pipeline:
1. **AST Tokenizer & Parser (`sql_validator.py`)**: Only `SELECT` and `WITH` CTE statements are permitted.
2. **Blocked Statements**: `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `TRUNCATE`, and multi-statement queries (`;`) are strictly rejected.
3. **Blocked Functions**: Dangerous backend functions (`pg_sleep`, `pg_read_file`, `dblink`, etc.) are blocked.
4. **PostgreSQL Read-Only Mode**: Even if AST validation were bypassed, PostgreSQL's transaction manager aborts any write.

### 3. File & Storage Security
* Uploaded files and catalog downloads are stored on disk with UUID filenames (`<uuid>.ext`).
* Strict path canonicalization prevents directory traversal attacks outside `upload_dir`.
* Maximum file size limit enforced (default 50 MB).

## 📊 Supported Dataset Formats

| Format | Extensions | Validation & Parsing Engine |
| :--- | :--- | :--- |
| **CSV** | `.csv` | UTF-8 / Latin-1 text decoding, non-empty row validation |
| **Excel** | `.xlsx` | `openpyxl` container verification, sheet inspection |
| **JSON** | `.json` | Array of records / JSON dictionary validation |
| **Parquet** | `.parquet` | `pyarrow` metadata and column inspection |

*(Note: PDF, images, Word documents, and audio formats are explicitly not supported for relational SQL ingestion).*

## 🚀 API Endpoints Overview

### Health & Root
* `GET /health` / `GET /api/v1/health`: Operational health check (API status, PostgreSQL connectivity).
* `GET /`: API version and documentation links.

### Authentication (Admin)
* `POST /api/v1/admin/auth/login`: Admin login returning HMAC Bearer token.

### Admin Dataset Management
* `POST /api/v1/admin/datasets/upload`: Upload custom dataset (CSV, XLSX, JSON, Parquet).
* `GET /api/v1/admin/datasets`: List all uploaded datasets.
* `GET /api/v1/admin/datasets/{dataset_id}`: Retrieve dataset metadata.
* `DELETE /api/v1/admin/datasets/{dataset_id}`: Safely delete stored file and database record.
* `POST /api/v1/admin/datasets/{dataset_id}/process`: Parse, clean, profile, and infer types.
* `POST /api/v1/admin/datasets/{dataset_id}/import`: Dynamically create PostgreSQL table and insert rows.
* `POST /api/v1/admin/datasets/{dataset_id}/prompts/regenerate`: Re-generate schema-driven prompts.

### Public Dataset Hub & AI Recommendations
* `GET /api/v1/datasets/catalog`: Browse popular datasets (filter by category).
* `GET /api/v1/datasets/catalog/categories`: List categories with dataset counts.
* `GET /api/v1/datasets/catalog/{catalog_id}`: Inspect catalog dataset details.
* `POST /api/v1/datasets/catalog/{catalog_id}/use`: Provision catalog dataset via unified ingestion.
* `POST /api/v1/datasets/recommendations`: Natural language dataset recommendation assistant.
* `GET /api/v1/datasets/{dataset_id}/prompts`: Fetch 5–8 one-click analytical questions.
* `GET /api/v1/datasets/{dataset_id}/schema`: Fetch live PostgreSQL column schema.

### AI Agent Chat (React-Ready)
* `POST /api/v1/chat`: Frontend-independent natural language query endpoint with multi-turn memory and chart hints.

## 💻 Running the Application

### 1. Start the FastAPI Backend
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
API Documentation will be available at: `http://localhost:8000/docs`

### 2. Start the Streamlit Analytics Interface
```bash
streamlit run streamlit.py --server.port 8501
```
